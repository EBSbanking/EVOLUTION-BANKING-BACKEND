# EVOLUTION BANKING BACKEND

This is the backend service for Evolution Banking, built with Node.js and Express.

## 🚀 Features

- User authentication
- Account management
- Transaction policies
- Loan and deposit handling

## 🛠️ Setup

```bash
git clone https://github.com/EBSbanking/EVOLUTION-BANKING-BACKEND.git
cd EVOLUTION-BANKING-BACKEND
npm install
npm start
